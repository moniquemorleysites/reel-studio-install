# Reel Studio installer

Sets up a Mac for the Reel Studio team. You need an invite from Monique first.

Open Terminal (press Cmd+Space, type Terminal), paste this line and press Enter:

```bash
curl -fsSL https://raw.githubusercontent.com/moniquemorleysites/reel-studio-install/main/install.sh | bash
```

It takes about 20 minutes and ends with Done. Safe to run again.

This repo only holds the installer. The tools live in a private repo it downloads after you sign in to GitHub.
Written by `library/team.py` in that repo; never edit it here.
